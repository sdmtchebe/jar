What Jarvis did

    Human-confirmed AI operations

    Jarvis Assistant

    A safe scaffold for a cloud-model Jarvis that can plan multi-agent work, browse the web, prepare file operations, draft communications, and ask for confirmation before taking side effects.

    Read the project README View source on GitHub
    • Uses cloud OpenAI-compatible model endpoints; no local model runtime required.
    • Limits computer access to configured workspace roots.
    • Requires operator confirmation tokens before side effects.
    • Plans browser, Google Workspace, email, and SMS actions before execution.

    Multi-agent planning

    Splits goals into planner, researcher, browser, file, communication, and workspace tasks.

    Web and browser access

    Provides web-fetch support and a confirmation-first browser interaction adapter.

    File operations

    Reads and writes files only within allowlisted directories and after approval.

    Messaging workflows

    Drafts email and SMS sends for explicit review before provider integrations execute them.
